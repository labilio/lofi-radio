# Product Requirements Document: 自定义副标题

**版本**: 1.0
**日期**: 2026-05-24
**作者**: Sarah (Product Owner)
**质量评分**: 90/100

---

## 概要

当前 Lofi Radio 主界面上电台名称下方的副标题是一行写死的文字 `Created by @SecretMaple24`，用户不可修改，也没有实用价值。

本需求将副标题改为**用户可选模式**：自动日期、自定义签名、时间问候语。用户通过设置窗口切换模式和输入内容，副标题实时反映到主界面。

---

## 问题陈述

**现状**: `index.html` 第 52 行硬编码 `<p class="subtitle">Created by @SecretMaple24</p>`。用户无法修改，也无法关闭。

**方案**: 副标题支持三种显示模式（日期 / 签名 / 问候语），默认启用问候语模式。用户在设置窗口中选择模式和输入签名内容，配置持久化到 `config.json`。

**业务价值**: 让界面上的每一个像素都属于用户——不再是「我的推特号」，而是对用户有用的信息。

## 用户故事

### Story 1: 切换副标题模式

**作为** Lofi Radio 用户
**我想要** 在设置窗口中选择副标题的显示模式
**以便** 那行小字显示对我有用的信息

**验收标准:**
- [ ] 设置窗口新增「副标题」配置区，包含模式选择器
- [ ] 三种可选模式：日期 / 自定义签名 / 问候语（默认）
- [ ] 切换模式后主界面副标题立即更新
- [ ] 模式选择持久化，重启后保留

### Story 2: 日期模式

**作为** Lofi Radio 用户
**我想要** 副标题显示当天的日期（英文格式）
**以便** 随时看到今天是几月几号星期几

**验收标准:**
- [ ] 格式示例：`Saturday, May 24`
- [ ] 每日 0 点后自动更新为新日期
- [ ] 日期格式固定为英文 `Weekday, Month DD`
- [ ] 与其他模式一样使用统一的副标题样式（颜色、字号不变）

### Story 3: 自定义签名模式

**作为** Lofi Radio 用户
**我想要** 输入一段自己的文字作为副标题
**以便** 展示个性化签名或当前状态

**验收标准:**
- [ ] 设置窗口提供文本输入框，最多 50 字符
- [ ] 输入后主界面立即更新
- [ ] 长文本超出时，CSS 自动截断并显示 `...`
- [ ] 鼠标悬停时通过 `title` 属性显示完整文本
- [ ] 签名为空时不显示副标题行

### Story 4: 问候语模式（默认）

**作为** Lofi Radio 用户
**我想要** 副标题根据当前时间自动显示对应的英文问候语
**以便** 每次打开 app 都感受到一点温度

**验收标准:**
- [ ] 时段与问候语映射：

| 时段 | 显示文字 |
|------|----------|
| 05:00 – 11:59 | Good morning |
| 12:00 – 17:59 | Good afternoon |
| 18:00 – 23:59 | Good evening |
| 00:00 – 04:59 | Good night |

- [ ] 每 60 秒检查一次时段变化，自动切换问候语
- [ ] 颜色与现有副标题样式统一，不随时间变化

## 功能需求

### 核心功能

**F1: 副标题模式系统**

三种模式：
- `greeting`（默认）— 自动问候语
- `date` — 自动日期
- `custom` — 用户自定义文本

切换逻辑：设置窗口发送 IPC `settings-subtitle-mode`，主进程更新 `config.json` 中的 `subtitleMode` 字段，同时通过 IPC 通知主窗口更新副标题。

**F2: 设置窗口扩展**

在 `settings.html` 中新增「副标题」配置区：
- 单选按钮组：三种模式的选择
- 文本输入框：仅在选择「自定义签名」时显示和可用
- 实时预览：修改后主界面立即更新

**F3: 文本溢出处理**

副标题 CSS 新增：
```css
overflow: hidden;
white-space: nowrap;
text-overflow: ellipsis;
```

- 不换行，像素级截断
- 自定义签名模式下，`title` 属性显示完整文本

**F4: 主界面更新机制**

`widget.js` 新增 `updateSubtitle(mode, text)` 方法：
- 日期模式：读取当前日期，拼接格式化字符串
- 问候语模式：读取当前时间，匹配时段
- 自定义模式：读取用户输入的文本
- 每 60 秒轮询刷新（仅日期和问候语模式）

### 排除范围

- ❌ 不同电台绑定不同副标题
- ❌ 多项目计时标记
- ❌ 副标题颜色/字体自定义
- ❌ 多语言支持（仅英文）

## 技术约束

### 性能
- 副标题更新逻辑：纯粹字符串操作 + DOM 文本替换，< 1ms
- 60 秒轮询：与现有 FocusTimeManager 的 `setInterval` 同一量级，无感知

### 存储
- 配置项存入现有 `config.json`（`subtitleMode` + `subtitleCustomText`）
- 无需新增存储 key

### 技术栈
- 纯 vanilla HTML/CSS/JS
- 设置窗口修改参考现有 `settings.html` / `settings.js` / `settings.css`
- 主界面更新参考现有 `widget.js`

### 兼容性
- 从旧版本升级的用户：首次启动时 `subtitleMode` 为空，默认使用问候语模式
- `config.json` 新增字段向前兼容，不影响已有配置

## 风险评估

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|----------|
| 用户输入超长文本破坏布局 | 中 | 低 | CSS `text-overflow: ellipsis` + `white-space: nowrap` 兜底 |
| 系统时间被手动修改导致问候语跳变 | 低 | 低 | 不影响功能，用户自行承担 |
| config.json 字段缺失（升级场景） | 中 | 低 | 读取时提供默认值 `{ subtitleMode: 'greeting', subtitleCustomText: '' }` |
