## 🎵 简介

这是一款精简小巧的桌面音乐播放器，挂在屏幕上，**就像把咖啡店的背景音乐搬进你的书房。**

- **两种模式**：黑胶唱片 / 灵动岛风格，想安静挂着时就切成小胶囊
- **21 种电台**：Lo-fi、Chill、Jazz、古典、雨声……学习和工作时总能找到合适的一档
- **无限不重复**：播放的是 7×24 小时在线电台，不是听几遍就腻的固定歌单
- **全局快捷键**：随时播放暂停、隐藏窗口，不用离开正在做的事
- **专注计时**：顺手记录今天真正专注了多久

## ✨ 功能特点

- **沉浸体验**：7×24 小时无限播放，超级适合学习、写作、编码和安静工作
- **轻量设计**：仅 120 MB+，无需复杂配置，下载后打开即可收听**无限不重复**的专注音乐
- **双形态切换**：
  - 普通模式：旋转发光的黑胶唱片质感
  - Mini 模式：仿灵动岛设计，缩成一个安静的小胶囊
- **全局可自定义快捷键**：
  - 播放 / 暂停：默认 `Alt + Q`（Windows）/ `Option + Q`（macOS）
  - 显示 / 隐藏：默认 `Alt + W`（Windows）/ `Option + W`（macOS）
  - Windows 在右下角系统托盘打开设置；macOS 在顶部右侧菜单栏打开设置
- **专注计时**：记录今日专注时长，每日自动重置
- **记住偏好**：自动记住上次选择的电台，下次打开继续播放
- **开机自启**：安装版可在设置中开启，打开电脑就有熟悉的背景音乐
- **一键静音**：点击小喇叭即可静音
- **自动检查更新**：每次打开检查一次；跳过某一版本后，下一个新版本仍会再次提醒

## 💡 你为什么要用这个？

### 不是在「听歌」，而是在「营造环境」

打开它，就像走进一家安静的咖啡店。

> 只有音乐，没有歌词，没有弹幕，没有干扰
>
> 你是来把事情做完的，不是来消费内容的

### 21 种电台，而不是一个歌单

7×24 小时自动播放，**无限不重复**。

> QQ 音乐 / 网易云是歌单逻辑，听完容易腻
>
> Lo-fi、Jazz、古典、雨声和更多风格，总有一档适合你当下的状态

### 随时可控，一键暂停

`Alt + Q`（Windows）/ `Option + Q`（macOS）

> 不需要切出窗口，专注不中断

### 即开即用，不设门槛

**不翻墙**，不用 YouTube / Spotify。

> 任意一台联网电脑，打开就能用

### 精简小巧，才是真正的沉浸

没有歌词滚动，没有 MV，没有社交功能。

> 一个小部件挂在屏幕上，安静陪伴
>
> 像咖啡店的背景音乐那样自然存在

### 学习 APP 和音乐 APP，为什么不能放在一起？

既然来听专注音乐，本质目的就是专注。

> 那为什么不顺手做一个
>
> 类似 Forest / 番茄 To Do 的学习计时器？

### 电脑上为什么不能有灵动岛？

灵动岛是一个很好的交互设计，但它只存在于手机上。

> 如果把播放器 + 计时器塞进一个电脑端的小胶囊
>
> 这件事本身就很有想象力

```bash
cd lofi-radio
npm install
npm start
```
